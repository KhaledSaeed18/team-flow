![The command palette](/screenshots/palette.png)

Press <kbd>⌘</kbd> <kbd>K</kbd> (or <kbd>Ctrl</kbd> <kbd>K</kbd>), or <kbd>/</kbd>, to open the command palette. It
searches tasks, projects and actions together.

Search understands:

- **Identifiers:** `RF-12` goes straight to that task.
- **Words as you type:** `calib enc` matches "Calibrate wheel encoders".
- **Typos:** `batery telemtry` still finds "Battery telemetry over CAN".
- **Comments:** a task can be found by what was said about it, and the result shows the comment that matched.

## Shortcuts

Press <kbd>?</kbd> anywhere to see them in the app.

| Keys                                     | Action                               |
| ---------------------------------------- | ------------------------------------ |
| <kbd>⌘</kbd> <kbd>K</kbd> / <kbd>/</kbd> | Command palette                      |
| <kbd>c</kbd>                             | Create a task in the current project |
| <kbd>g</kbd> <kbd>b</kbd>                | Go to the board                      |
| <kbd>g</kbd> <kbd>l</kbd>                | Go to the list                       |
| <kbd>g</kbd> <kbd>c</kbd>                | Go to the calendar                   |
| <kbd>g</kbd> <kbd>p</kbd>                | Go to planning                       |
| <kbd>g</kbd> <kbd>i</kbd>                | Go to the inbox                      |
| <kbd>?</kbd>                             | Show shortcuts                       |

On the board:

| Keys             | Action                                            |
| ---------------- | ------------------------------------------------- |
| Arrow keys       | Move between cards and into a card                |
| <kbd>Enter</kbd> | Open the card, or pick it up from its move handle |
| <kbd>Tab</kbd>   | While dragging: the next drop position            |
| <kbd>Esc</kbd>   | Cancel a drag, or close the task panel            |
