# 0003 — Drizzle ORM and SQL-first migrations

- Status: Accepted
- Date: 2026-10-29

## Context

v1 used Prisma with a committed generated client. v2 leans on Postgres features (composite foreign keys, partial
and GIN indexes, `tsvector` columns, `LISTEN/NOTIFY`, advisory locks) and wants queries whose SQL is obvious.

## Decision

- **Drizzle ORM** with the `postgres` (postgres.js) driver; schema in TypeScript under `packages/db/src/schema`.
- Migrations are generated by `drizzle-kit generate`, reviewed as SQL and committed; hand-written SQL migrations
  are allowed for things Drizzle cannot express (triggers, functions).
- No generated client to commit: types come from the schema at compile time.

## Consequences

- Schema, types and queries live in one language with no codegen step.
- We own more SQL; reviews read the migration file, not just the schema diff.
